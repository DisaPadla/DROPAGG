# 🚀 Бесплатный деплой проекта на Vercel + Neon / Supabase (Монолит Next.js)

Проект **уже полностью адаптирован** для 100% бесплатного деплоя в качестве Vercel-монолита без серверов, Redis или платных воркеров!

---

## ⚡ Что уже сделано в коде проекта:

1. **Бессерверный фоновый синхронизатор (`src/lib/serverless-ingestor.ts`)**:
   - Автоматически работает без Redis и BullMQ на бесплатном тарифе Vercel.
2. **Vercel Cron (`vercel.json`)**:
   - Автоматически запускает авто-обновление магазинов каждые 6 часов совершенно бесплатно.
3. **PGlite WASM / Local-First клиент**:
   - Работает прямо в браузере пользователя, разгружая базу данных.

---

## 📋 Пошаговая инструкция по деплою (Бесплатно навсегда):

### Шаг 1: Создание бесплатной базы данных PostgreSQL

Выберите любой из бесплатных облачных провайдеров PostgreSQL:

#### Вариант A: Neon.tech (Рекомендуется)
1. Зарегистрируйтесь на [neon.tech](https://neon.tech) через GitHub.
2. Нажмите **Create Project** -> Имя: `dropagg-db`.
3. Скопируйте строку подключения `DATABASE_URL` (например, `postgres://alex:pass@ep-cool-lake-123456.us-east-2.aws.neon.tech/neondb?sslmode=require`).

#### Вариант B: Supabase
1. Зарегистрируйтесь на [supabase.com](https://supabase.com).
2. Создайте новый проект -> Скопируйте `DATABASE_URL` из раздела *Project Settings -> Database*.

---

### Шаг 2: Применение миграций базы данных

Перед запуском выполните команду в консоли для создания таблиц в вашей облачной БД:

```bash
DATABASE_URL="ваша_строка_подключения_neon_или_supabase" npx prisma db push
```

---

### Шаг 3: Деплой на Vercel в 1 клик

1. Загрузите проект в ваш **GitHub репозиторий**.
2. Перейдите на [vercel.com/new](https://vercel.com/new) и импортируйте ваш репозиторий.
3. В разделе **Environment Variables** добавьте переменные окружения:

| Переменная | Значение | Описание |
| :--- | :--- | :--- |
| `DATABASE_URL` | `postgres://...` | Ваша строка подключения к Neon / Supabase |

4. Нажмите **Deploy**! ✨
